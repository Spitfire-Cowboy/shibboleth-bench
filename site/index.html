What it is

A small benchmark for counting errors, mirror/reflection mismatches, malformed text, attachment failures, and other visible anomalies.

What it is not

Not a general multimodal score. Every claim here is only about this checked-in dataset and these checked-in snapshots.

How to read it

Start with the snapshot tables. Then use the hardest-items table. Open per-item details only when you need the model-by-model rows.

Dataset shape
